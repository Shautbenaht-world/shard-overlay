# Shard Overlay

Stream overlay for Dota 2: event plates for all 10 players, widgets, timers, second screen, match history.

Download the latest `Shard Overlay.exe` from [Releases](https://github.com/Shautbenaht-world/shard-overlay/releases/latest).
The program checks this page and tells you when a new version is out.
